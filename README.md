# Learning C

This repository documents my progress learning the C programming language from the ground up, following the [C Programming Tutorial on GeeksforGeeks](https://www.geeksforgeeks.org/c/c-programming-language/).

## Motivation

My primary language is C++, which I use for competitive programming, but I have not formally studied C. This repository exists to strengthen my understanding of the fundamentals — particularly the aspects that C++'s abstractions tend to obscure, such as pointers, manual memory management, and lower-level program behavior.
